# Curso de React con TypeScript

Este repositorio reúne mis ejercicios, proyectos de práctica y apuntes mientras avanzo en un curso de React con TypeScript. Mi objetivo es fortalecer mis bases de desarrollo frontend y aprender a construir interfaces mediante componentes reutilizables, tipos y buenas prácticas de código.

El contenido se organiza por etapas para mostrar mi progreso: desde el reforzamiento de JavaScript y TypeScript hasta los primeros pasos con React. Incluyo apuntes con explicaciones y ejemplos para documentar lo aprendido y facilitar su consulta.

## Estado del curso

En progreso. Actualmente, el repositorio incluye ejercicios de fundamentos de JavaScript y TypeScript, además de un proyecto inicial de React generado con Vite. Iré incorporando nuevas prácticas conforme avance en el curso.

## Tecnologías y herramientas

- **JavaScript y TypeScript:** fundamentos del lenguaje y tipado del código.
- **React:** construcción de interfaces con componentes.
- **Vite:** entorno de desarrollo y generación de proyectos.
- **ESLint:** análisis del código según las reglas configuradas.
- **CSS:** estilos de la interfaz.

## Ejecutar un proyecto

Cada proyecto tiene sus propias dependencias. Por ejemplo, para iniciar el proyecto de primeros pasos:

```bash
cd 01-first-steps
npm install
npm run dev
```

Otros comandos disponibles dentro de cada proyecto:

```bash
npm run lint    # Revisar el código con ESLint
npm run build   # Comprobar tipos y generar la versión de producción
npm run preview # Previsualizar la versión generada
```

Para crear un nuevo proyecto con Vite durante el curso:

```bash
npm create vite
```
